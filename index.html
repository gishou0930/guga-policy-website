01 / SCOPE

適用範圍

About this application

咕嘎 AI Threads 是由使用者安裝並在自己的 Windows 電腦上執行的本機工具，用於建立 Threads 貼文草稿、讀取留言或公開貼文，以及在使用者確認後發布內容。本工具沒有集中式帳號系統或雲端資料庫；資料由執行本工具的使用者在自己的裝置上管理。

Guga AI Threads is a local application installed and run by the user on a Windows computer. It creates Threads drafts, reads replies or public posts, and publishes content after the user confirms. The application does not operate a centralized account system or cloud database; the person running it manages the data on their own device.

02 / DATA

處理的資料

Information handled by the app

  • Threads 連線資料

    Threads User ID、帳號名稱、Access Token 和 App Secret，用於驗證帳號及呼叫 Threads API。

    Threads user ID, username, access token, and app secret, used to connect the account and call the Threads API.

  • 你建立或編輯的內容

    咕嘎人設、創作指示、貼文草稿、留言回覆草稿，以及草稿狀態和已發布的貼文／回覆 ID。

    Guga's persona, your writing instructions, post drafts, reply drafts, draft status, and IDs of published posts or replies.

  • 從 Threads 讀取的內容

    依功能讀取的貼文文字、作者名稱、公開連結、時間、留言與回覆內容，以及海巡關鍵字搜尋結果。

    Depending on the feature, post text, author names, public links, timestamps, comments and replies, and keyword search results.

  • 圖片與技術資訊

    使用者提供的圖片網址，以及應用程式的本機啟動和錯誤診斷記錄。圖片只會在處理時暫存在記憶體；本工具將圖片網址保存在草稿資料中，不會保存圖片副本。

    Image URLs you provide and local startup or error diagnostics. Image bytes are held in memory while being processed; the app stores the image URL with a draft, not a local image copy.

03 / PURPOSE

資料用途與傳輸

How information is used and shared

上述資料只用於提供帳號連線、讀取 Threads 內容、搜尋公開貼文、產生草稿，以及在你按下發布後建立貼文或回覆。咕嘎不會自動發布留言，也不會將資料出售或用於廣告。

The information above is used to connect your account, read Threads content, search public posts, generate drafts, and create a post or reply only after you choose to publish. Guga does not publish replies automatically, sell the data, or use it for advertising.

LOCAL · OLLAMA

本機 Qwen 模型

預設情況下，貼文指示、貼文內容、回覆上下文及需要分析的圖片會傳給本機 Ollama（預設網址 127.0.0.1:11434）產生草稿。若你在 `.env` 將 Ollama 網址改成遠端服務，資料也會傳給該服務。

By default, writing instructions, post text, reply context, and images for analysis are sent to Ollama on your computer (default address 127.0.0.1:11434) to generate drafts. If you configure a remote Ollama server in .env, that server will receive the data.

META · THREADS API

Meta Threads

帳號識別資料、Token、搜尋字詞及執行功能所需的貼文／留言資料會透過 Threads API 傳給 Meta。發布時，貼文或回覆內容及必要的圖片網址也會傳給 Meta；Meta 對資料的處理依其政策辦理。

Account identifiers, access tokens, search terms, and the post or reply data needed for a feature are sent to Meta through the Threads API. When you publish, the post or reply text and any required image URL are also sent to Meta and handled under Meta's policies.

04 / STORAGE

保存與安全

Where information is kept

  • Token 和 App Secret：保存在 Windows Credential Manager，不回填到設定頁。
  • 草稿、人設及讀取紀錄：保存在本機 SQLite 資料庫，預設位置為 data/guga_threads.sqlite3；使用者可透過 `.env` 設定其他位置。
  • 診斷記錄：保存在本機專案的 logs/startup.log。較早版本可能記錄 API 請求網址；目前啟動器已降低 HTTPX 請求網址的記錄層級。若舊記錄曾保存 Token，請撤銷該 Token 並刪除舊記錄。

Access tokens and app secrets are kept in Windows Credential Manager and are not filled back into the settings page. Drafts, persona settings, and retrieved records are stored in a local SQLite database (default: data/guga_threads.sqlite3); the user can configure a different path in .env. Diagnostics are stored locally in logs/startup.log. Older versions may have logged API request URLs; the current launcher suppresses HTTPX request URL logs. Revoke any token that may appear in an older log, then delete that log.

資料安全也取決於你裝置上的 Windows 帳號、磁碟及備份設定。請只在你信任的電腦上使用本工具，並保護本機檔案和帳號。

Data security also depends on your Windows account, disk, and backup settings. Use the app only on a computer you trust and protect its local files and account.

05 / RETENTION

保留與刪除

Retention and deletion

本機資料會保留至你在應用程式中刪除草稿、移除連線，或刪除本機資料庫與診斷記錄。移除本機 Token 不會自動刪除已發布在 Threads 的內容，也不一定會撤銷 Meta 端的應用程式授權。完整刪除步驟請見 資料刪除說明。

Local data remains until you delete drafts, remove the saved connection, or delete the local database and diagnostic logs. Removing the local token does not delete content already published on Threads and may not revoke the app authorization at Meta. See the data deletion instructions for full steps.
